## 四、遇到的问题及解决方案

### 4.1 问题1：CUDA不可用

| 属性 | 内容 |
|-----|------|
| 问题描述 | 系统无NVIDIA GPU，训练只能在CPU上运行，速度极慢 |
| 发生时间 | 2026-07-18 |
| 影响范围 | 所有模型训练任务 |
| 解决方案 | 降低训练轮数（100→30 epochs），使用YOLOv8n小型模型 |
| 实施过程 | 修改配置文件中的epochs参数，从100降低到30 |
| 效果 | 训练时间从预估24小时缩短到2-3小时 |
| 遗留问题 | CPU训练仍较慢，模型精度可能受影响 |

### 4.2 问题2：类别索引无效

| 属性 | 内容 |
|-----|------|
| 问题描述 | 头盔数据集标注使用了非连续索引（3, 4），导致训练报错 `KeyError: 2-class dataset requires class indices 0-1` |
| 发生时间 | 2026-07-20 |
| 影响范围 | 头盔模型训练 |
| 解决方案 | 标准化类别索引为0-based连续索引（0: helmet, 1: no_helmet） |
| 实施过程 | 修改`helmet_dataset.yaml`配置，并运行`fix_labels.py`修正标注文件 |
| 效果 | 训练成功启动并完成 |

**关键文件**:
- [fix_labels.py](file:///e:/output/1/zhitong/training/fix_labels.py) - 标签修正脚本
- [helmet_dataset.yaml](file:///e:/output/1/zhitong/data/helmet_dataset.yaml) - 数据集配置

### 4.3 问题3：视频抽帧失败

| 属性 | 内容 |
|-----|------|
| 问题描述 | 部分视频文件因`mpeg4 header damaged`错误无法提取帧 |
| 发生时间 | 2026-07-18 |
| 影响范围 | 数据采集 |
| 解决方案 | 使用现有`processed_frames`数据结合增强技术扩充数据集 |
| 实施过程 | 基于现有数据进行水平翻转、旋转、亮度调整等增强操作 |
| 效果 | 数据集达到要求的≥200张图像/类别 |
