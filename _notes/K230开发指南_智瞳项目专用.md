# K230 开发指南 - 智瞳灵声项目专用

## 一、K230 平台概述

### 1.1 硬件规格
- **芯片**: Kendryte K230 (双核RISC-V)
- **NPU**: 0.5TOPS算力，支持kmodel格式模型
- **摄像头**: MIPI-CSI接口，最高1080P
- **显示**: ST7701 LCD屏 (640x480) / HDMI输出
- **网络**: WiFi 802.11 b/g/n
- **音频**: 麦克风 + 扬声器
- **存储**: SD卡 (最大128GB)
- **串口**: UART x2 (默认115200波特率)

### 1.2 开发环境
- **编程语言**: MicroPython (CanMV IDE)
- **模型格式**: .kmodel (nncase转换工具)
- **调试方式**: CanMV IDE 串口调试 / SD卡离线运行
- **固件位置**: SD卡根目录

```python
import socket
import ujson

# HTTP POST上传图片
def upload_image(url, image_path):
    s = socket.socket()
    addr = socket.getaddrinfo("your-server.com", 80)[0][-1]
    s.connect(addr)
    
    with open(image_path, 'rb') as f:
        img_data = f.read()
    
    boundary = "----WebKitFormBoundary"
    body = (
        f"--{boundary}\r\n"
        f"Content-Disposition: form-data; name=\"image\"; filename=\"photo.jpg\"\r\n"
        f"Content-Type: image/jpeg\r\n\r\n"
    ).encode() + img_data + f"\r\n--{boundary}--\r\n".encode()
    
    header = (
        f"POST /api/upload HTTP/1.1\r\n"
        f"Host: your-server.com\r\n"
        f"Content-Type: multipart/form-data; boundary={boundary}\r\n"
        f"Content-Length: {len(body)}\r\n\r\n"
    ).encode()
    
    s.send(header + body)
    response = s.recv(4096)
    s.close()
    return response
```

## 四、自定义模型训练与部署

### 4.1 三种训练方案对比

| 方案 | 难度 | 成本 | 灵活度 | 推荐场景 |
|------|------|------|--------|---------|
| **嘉楠在线训练平台** | ⭐ 简单 | 免费/付费 | 中 | 快速验证、小数据集 |
| **本地YOLO训练 + nncase转换** | ⭐⭐⭐ 中等 | 免费 | 高 | 专业开发、大数据集 |
| **AI Cube本地训练** | ⭐⭐ 一般 | 免费 | 中 | 离线环境、快速原型 |

**指挥官推荐**：智瞳项目优先使用「本地YOLOv8训练 + nncase转换」方案，灵活度最高，可完全控制训练过程。

#### 4.2.2 数据集要求

**目标检测数据集格式**：
```
dataset/
├── images/
│   ├── train/
│   │   ├── img001.jpg
│   │   └── img002.jpg
│   └── val/
│       ├── img003.jpg
│       └── img004.jpg
└── labels/
    ├── train/
    │   ├── img001.txt
    │   └── img002.txt
    └── val/
        ├── img003.txt
        └── img004.txt
```

**YOLO标注格式**（每一行一个目标）：
```
class_id x_center y_center width height
```
- class_id: 类别索引（从0开始）
- x_center, y_center: 中心点坐标（归一化到0-1）
- width, height: 宽高（归一化到0-1）

**标注工具推荐**：LabelImg、LabelStudio、Roboflow

#### 4.2.3 训练流程

1. 注册嘉楠开发者平台账号
2. 创建项目，选择任务类型（目标检测/分类/分割等）
3. 上传数据集（图片 + 标注文件）
4. 配置训练参数（迭代次数、学习率、骨干网络等）
5. 开始训练，等待完成
6. 下载训练产物：
   - `best.kmodel` - 转换好的K230模型文件
   - `deploy_config.json` - 部署配置文件
   - `mp_deployment_source.zip` - 完整部署包

#### 4.2.4 deploy_config.json 详解

```json
{
    "chip_type": "k230",
    "model_type": "AnchorBaseDet",
    "img_size": [640, 640],
    "categories": ["Screwdriver", "Band"],
```

**关键字段说明**：

- `mean`/`std`: 图像归一化参数
- `confidence_threshold`: 置信度阈值
- `nms_threshold`: NMS非极大值抑制阈值

#### 4.3.3 训练模型

```python
from ultralytics import YOLO

# 加载预训练模型（从头训练用yolov8n.yaml）
model = YOLO('yolov8n.pt')

# 开始训练
results = model.train(
    data='violation_dataset/data.yaml',
    epochs=100,           # 训练轮次
    imgsz=320,            # 输入图像尺寸（K230建议224-640）
    batch=16,             # 批次大小
    device='0',           # GPU设备
    patience=20,          # 早停耐心值
    lr0=0.01,             # 初始学习率
    lrf=0.01,             # 最终学习率因子
    optimizer='SGD',      # 优化器
    weight_decay=0.0005,  # 权重衰减
    momentum=0.937,       # 动量
    warmup_epochs=3,      # 预热轮次
    augment=True,         # 数据增强
    fliplr=0.5,           # 水平翻转概率
    mosaic=1.0,           # 马赛克增强
    mixup=0.0,            # 混合增强
    close_mosaic=10,      # 最后N轮关闭马赛克
    project='runs/train',
    name='violation_detect',
    val=True,            # 训练中验证
    save=True,           # 保存模型
    plots=True,          # 生成图表
)

# 验证模型
metrics = model.val()
print(f"mAP50: {metrics.box.map50}")
print(f"mAP50-95: {metrics.box.map}")
```

#### 4.3.5 nncase转换为kmodel

```bash
# 使用nncase命令行工具转换
ncc compile best.onnx best.kmodel -i onnx -t k230 \
  --target k230 \
  --input-mean "0,0,0" \
  --input-std "255,255,255" \
  --input-layout "NHWC" \
  --output-layout "NCHW" \
  --preprocess \
  --calibrate-method "no_quant" \
  --dump-ir

# 量化（可选，提升推理速度）
ncc compile best.onnx best_int8.kmodel -i onnx -t k230 \
  --target k230 \
  --input-mean "0,0,0" \
  --input-std "255,255,255" \
  --input-layout "NHWC" \
  --output-layout "NCHW" \
  --preprocess \
  --calibrate-method "kld_m0" \
  --dataset calibration_images/ \
  --dump-ir
```

**量化说明**：
- **FP16/FP32**：精度高，速度慢，调试推荐
- **INT8量化**：速度快2-4倍，精度略有下降，部署推荐
- 量化需要校准数据集（100-500张代表性图片）

**数据集需求**：

- 验证集：500-1000张
- 场景覆盖：白天/夜晚、晴天/雨天、不同角度

**训练配置**：
```python
model = YOLO('yolov8n.pt')
model.train(
    data='violation_cars/data.yaml',
    epochs=150,
    imgsz=320,
    batch=32,
    device='0',
    patience=30,
    optimizer='SGD',
    lr0=0.01,
```

## 五、YbProtocol串口协议

### 5.1 协议格式
```
$长度,功能ID,数据1,数据2,...,数据N#
```

- **起始符**: `$`
- **结束符**: `#`
- **分隔符**: `,`
- **长度**: 整个数据帧的字节数

### 5.3 STM32端解析示例
```c
// 协议头/尾定义
#define PTO_HEAD '$'
#define PTO_TAIL '#'
#define PTO_BUF_LEN_MAX 128

// 接收状态机
void Pto_Data_Receive(uint8_t Rx_Temp) {
    static uint8_t RxBuffer[PTO_BUF_LEN_MAX];
    static uint8_t RxIndex = 0;
    static uint8_t RxFlag = 0;
    
    switch(RxFlag) {
        case 0: // 等待起始符
            if(Rx_Temp == PTO_HEAD) {
                RxBuffer[0] = PTO_HEAD;
                RxFlag = 1;
                RxIndex = 1;
            }
            break;
        case 1: // 接收数据
            RxBuffer[RxIndex++] = Rx_Temp;
            if(Rx_Temp == PTO_TAIL) {
                // 解析完整帧
                Pto_Data_Parse(RxBuffer, RxIndex);
                RxFlag = 0;
                RxIndex = 0;
            }
            break;
    }
}
```

## 八、常见问题排查

### 8.1 模型加载失败
- **原因**: kmodel路径错误 / 模型不兼容
- **排查**: 
  - 检查SD卡路径是否正确
  - 确认模型是K230专用kmodel格式
  - 使用nncase工具重新转换模型

### 8.2 摄像头无图像
- **原因**: 摄像头未连接 / 配置错误
- **排查**:
  - 检查摄像头排线是否插好
  - 确认sensor初始化参数正确
  - 尝试降低分辨率测试

### 8.3 WiFi连接失败
- **原因**: SSID/密码错误 / 信号弱
- **排查**:
  - 确认WiFi是2.4GHz频段
  - 检查密码是否正确
  - 靠近路由器测试

### 8.4 串口通信异常
- **原因**: 波特率不匹配 / TX RX接反
- **排查**:
  - 确认两边波特率都是115200
  - 检查TX接RX，RX接TX
  - 使用USB-TTL模块调试

### 8.5 内存不足
- **原因**: 模型太大 / 同时运行多个任务
- **排查**:
  - 使用gc.collect()及时回收
  - 降低模型输入分辨率
  - 关闭不必要的功能
