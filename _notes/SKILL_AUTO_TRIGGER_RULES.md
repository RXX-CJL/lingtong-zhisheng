## 一、自动触发机制

### 触发优先级
1. 用户明确调用 `/skill_name` → 最高优先级，立即执行
2. 系统检测到意图匹配 → 自动调用对应 Skill
3. 无匹配 → 正常文本响应

### 调用流程
```
用户输入 → 意图分析 → 匹配 Skill → 自动调用 → 返回结果
```

## 三、智能意图识别规则

### 规则 1：关键词匹配
- 如果输入包含 "创建网站"、"构建页面" → 自动调用 web-dev
- 如果输入包含 "PPT"、"演示文稿" → 自动调用 slides
- 如果输入包含 "图表"、"可视化" → 自动调用 chart-visualization

### 规则 2：上下文推断
- 如果正在讨论前端开发，用户说 "帮我美化一下" → 自动调用 frontend-design
- 如果正在讨论数据报告，用户说 "帮我做个图表" → 自动调用 chart-visualization

### 规则 3：反问确认
- 如果意图不够明确，先反问确认：
  > "你是想要创建一个新网站吗？我可以调用 web-dev Skill 来完成。"

## 四、指挥官授权机制

### 自动调用条件
1. 意图明确匹配（≥80% 置信度）
2. 用户未明确拒绝过该 Skill
3. 符合当前项目上下文

### 需要手动确认的情况
1. 意图模糊（<80% 置信度）
2. 涉及敏感操作（删除文件、修改核心配置）
3. 用户首次使用该 Skill

---

## 五、记忆锚点

> 每次回复前检查：
> 1. 用户输入是否匹配任何 Skill 触发关键词？
> 2. 如果匹配，置信度是否足够自动调用？
> 3. 是否需要先确认用户意图？
> 4. 调用前是否需要检查上下文？
