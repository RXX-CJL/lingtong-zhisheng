## 三、多对话并发作业守则（★2026-10-05 新增）

**背景**：多个对话可能同时在同一个 `E:\output` 工作区作业，**会互相覆盖文件**。

### 三条规则

1. **写文件前先看修改时间**
   ```
   若目标文件的修改时间 = 刚刚（几分钟内）-> 另一个对话正在写它
   -> 不要改它，改为【新建一个带后缀的文件】或先问用户
   ```

2. **新建优于覆盖**
   ```
   推荐:  _camera_verdict_v2.md   或   _camera_verdict_20261005.md
   避免:  直接改写 _camera_verdict.md
   ```

3. **工作区记忆是共享的，写入要走 memory_update**
   ```
   不要手工编辑 memory/*.md（Host 管并发与版本校验）
   已有条目优先【更新】，不要重复创建
   ```

### 分工建议（如果确实要并行）

| 分工方式 | 说明 |
|---|---|
| **按文件分** | 对话 A 只写 `_camera_*.md`，对话 B 只写 `_tl_*.md` |
| **按阶段分** | 一个对话"探索/实验"，另一个"固化/验证" |
| **主从分** | 一个主对话负责综合，其余只做专项并回写结论 |
