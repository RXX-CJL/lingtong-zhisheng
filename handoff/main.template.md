## 八、评测口径结案（2026-11-01，**推翻上一轮判断**）

> 全文在 F:/AI/DSH-HQ/_tmp/EVAL-VERDICT.md。这里只留结论。

**一句话**：我们一直用「抄原文能不能找到自己」的尺子，去判「用自己的话能不能找到记忆」。两者差 65 个百分点。

| 尺子 | query 词在 target 里的覆盖率 | @1 |
|---|---|---|
| 手工 12 题（真实提问） | **26%** | **17%** |
| E1/E2 抄正文句子 | 100% | 82% |
| E5 直接给标题 | 100% | 100% |
| E9/E10 抽稀有词 | 100% | **95%/87%** |
| E7 删掉稀有词 | 100%（但有效词只剩 2 个） | **21%** |

**三条反直觉**：
1. 越短的 query 反而越准（E9 95%）——因为抽的是 df<5% 的稀有词，等于 **query 里带了主键**。不是检索强，是白送。
2. 删掉稀有词 @1 从 82% 到 21%——**BM25 的表现几乎全部由「query 里有没有稀有词」决定**，跟排序公式关系很小。
3. 手工题有足够信息（有效词 11 个）但只有 26% 在 target 里 = **语义鸿沟**，不是排序问题。
   例：「想换个对话继续干活，有哪几种办法」在 target 里 **0%** 命中（target 用的是 session relay / 交接）。

**这解释了 D1 为什么必然失败**：在词汇不重合的题上，任何「位置类」信号都只能把常见词胜出的文档排更前。信号没错，用错了场景。

**下一步（结论，不是计划）**：
1. 承认两个场景分开评测：A 关键词检索（BM25 已够用 87~95%，**不用再优化**）；B 概念检索（17%，唯一值得投入）。
2. 场景 B 要的是**词汇桥接**，不是调参。三条路：同义词表（零依赖、覆盖窄）/ 向量检索（旧结论建立在场景 A 尺子上，**需重测**）/ 查询扩展（LLM 改写成记忆的说法）。
3. 评测集按场景 B 建，60~100 题，每题必须满足「问概念且目标记忆里没有这些词」。

**被推翻的旧结论（务必不要再犯）**：
- ❌「瓶颈是短文档偏置」——上一轮记的，错。真因是词汇不重合。
- ❌「手工题只是太少，扩大就好」——性质才关键，同性质扩量只会让 17% 更稳，不会变好。
- ❌「向量被否决」——那条建立在场景 A 的尺子上，场景 B 未验证。

### 9.1 银河风格（用户："球体模型实在不像宇宙的样子"）

真因：**银河里根本没有球**。节点被画成带光照的球体，与真实银河无关。

- 球改点：`wantOrb = isHover || isSel || nearFocus || n.kind==='stellar'`，常态只画核
- 节点色改真实恒星光谱（数据里 10 色本就同色系不同亮度，换色相不丢语义）
- 银河带：原 fillRect 旋转矩形渐变（硬边）→ 14 个椭圆径向渐变 + 核球 + 16 个暗尘

### 9.2 拉近修复（用户："拉近后之前的诡异设计还是存在"）

真因两件事叠加：

| 现象 | 真因 | 修法 |
|---|---|---|
| 又变回大圆球 | `r = n.size*13*p.s` 跟 zoom **线性放大**，4.5 倍时变 20-40px 圆盘 | `ZOOM_TAME=0.35` + `effR` 硬上限 2.6px、光晕上限 9px |
| 密如蜘蛛网 | 连线阈值固定 0.40，拉近后线被拉长堆积 | `minWeight` 随 zoom 递增 (0.40/0.52/0.66) + 亮度按 `zoomTame` 压暗 |

判据：**真实星空里星星再近也只是一个点，变的是亮度与位置，不是直径。**

### 9.3 恒星模型（用户："鼠标选中时还是之前的设计，橙黄黑"）

真因：那段代码画的是**行星**——`lightFall` 距离衰减 + planetshine 地照 + 晨昏线暖橙 + 夜面深蓝黑。
但节点是**恒星**，自发光，无暗面、无晨昏线。

重写为三层：色球柔光(r*2.6) → 光球（临边昏暗，不是黑）→ 核心白热（仅 r>2.4，0.26r）。
配色全程用本星颜色 `mixHex` 提亮/压暗，不写死白与黑。

### 9.4 轨道公转（用户："不再是三点一线，改成其它星球绕其旋转"）

真因：`pushOut` 沿**深度方向**推远（`depth + pushOut*2.0`），投影后全排成一条直线——
这就是"三点一线"。深度推远不改变屏幕角度，所以"谁挨着谁"根本看不出来。

改法：屏幕空间极坐标轨道。

| 维度 | 旧 | 新 |
|---|---|---|
| 位移 | 沿深度推远（投影成直线） | 屏幕平面绕焦点旋转（成环） |
| 半径 | 无 | **由关系强度决定**：强关联内圈、弱关联外圈 |
| 角速度 | 无 | 近轨道慢、远轨道快 |
| 相位 | 无 | 每颗星 id 哈希算固定初相位，不整体刚性旋转 |

深度推远压到 0.28/0.34（只保留"让开遮挡"作用）。**半径 = 关系强度**，一眼看出谁离得近。

**触发条件**：只有非 stellar 节点会启动轨道（`computeFocus` 对恒星直接 return null，"太阳升起一切都该亮着"）。
