任务目标：

在 EventDetail 增加“分析回放”体验：

- 保留原始证据视频；
- 提供分析回放模式；
- 在视频上只保留简洁中文标注和必要的车辆框；
- 在视频右侧增加车辆信息面板；
- 点击车辆后高亮对应车辆并显示详细信息；
- 单独显示 AI 判定和人工复核状态。

推荐布局：

```text
┌──────────────────────────┬──────────────────┐
│                          │ 车辆信息           │
│      视频/分析回放         │ ID 20             │
│  ID 20 · 逆行              │ 类型：汽车         │
│  简洁框线和状态颜色         │ 速度：72 km/h     │
│                          │ 车牌：宁A12345    │
│                          │ 违规：逆行         │
│                          │ 置信度：91%        │
└──────────────────────────┴──────────────────┘
```

实现边界：

- 中文信息优先用 HTML/CSS 叠加层显示，避免 OpenCV `putText` 无法正确渲染中文。
- 原始证据视频不能被覆盖或替换。
- 如果现有数据不具备逐帧轨迹，必须按 DSH 报告采用最小可行降级：展示事件车辆信息、关键帧和事件级标注，并明确注明逐帧回放暂不具备的数据原因。
- 不得伪造逐帧速度、车牌或车辆位置。
