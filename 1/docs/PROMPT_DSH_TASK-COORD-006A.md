任务目标：

为“事件分析回放”建立事实基础，确认现有代码和数据库能够支持以下界面：

```text
┌──────────────────────────┬──────────────────┐
│      视频/分析回放区域      │ 车辆信息面板       │
│  简洁中文标注和车辆框       │ ID、速度、车牌     │
│                          │ 违规、置信度、状态 │
└──────────────────────────┴──────────────────┘
```

需要回答：

1. 当前事件视频是否保存原始帧、检测框、track_id 和逐帧车辆信息；
2. 当前 `TrafficEvent`、`TrafficEventRecord`、`EvidenceChain` 能提供哪些车辆字段；
3. 当前 `trajectory` 是否足以驱动视频回放中的车辆位置；
4. EventDetail 现有接口和前端组件应如何扩展；
5. 是否需要新增事件回放数据接口，推荐响应结构是什么；
6. 中文标签应放在前端 HTML/CSS 叠加层、后端视频帧，还是两者组合；
7. 如何保留原始证据视频，同时提供分析回放；
8. 现有 7 个真实事件能否直接作为首批回放样本；
9. 最小实现需要修改哪些文件，哪些文件不应修改。
