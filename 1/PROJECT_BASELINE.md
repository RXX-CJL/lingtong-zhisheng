# 智瞳灵声项目基线

> 建立日期：2026-09-05
> 定位：当前真实状态快照，不替代任务记录，不代表所有功能已经验收。

## 1. 项目身份

- 项目名称：智瞳灵声-基于视觉识别与云端推理的智慧交管系统
- 项目目录：`E:\output\1`
- 项目类型：端云协同智慧交通违法检测与辅助治理系统
- 当前阶段：核心代码与多模块原型已形成，正在进入真实性核验、稳定性和工程收敛阶段

## 2. 当前技术栈

- 后端：Python 3.12、FastAPI、Uvicorn、SQLAlchemy、SQLite
- 前端：Vue 3、Vite、Element Plus、ECharts、Axios
- AI/视觉：Ultralytics YOLO、PaddleOCR 相关代码、OpenCV、云端视觉/判定调用代码
- 跟踪与事件：自定义 VehicleTracker、循环帧缓存、交通事件引擎、证据链
- 边缘与仿真：K230 资料和程序、CARLA 目录
- 数据：`api/zhitong_violations.db`、`api/zhitong.db`、图片上传目录及模型文件

| 目录/文件 | 实际作用 |

| `carla/` | CARLA 仿真环境和 Python API |
| `scripts/` | 脚本和演示辅助工具 |
| `tests/` | 事件、缓存、证据链、多帧和集成测试 |

## 4. 当前架构认知

现有代码呈现出以下链路：输入图像/视频/摄像头 → YOLO/本地视觉处理 → 规则或行为判定 → 可选车牌识别与多帧确认 → 云端协作/二次判断 → 违规或交通事件记录 → Web 管理端展示。事件相关代码还包含循环缓存、状态机和证据链模块。K230、CARLA、数字孪生和微信小程序属于独立模块或扩展链路，尚未在本次基线中完成端到端验收。
