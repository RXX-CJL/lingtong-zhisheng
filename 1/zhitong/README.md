# 智瞳灵声 - 基于视觉识别与云端推理的智慧交管系统

## 项目简介

智瞳灵声是一个基于端云协同架构的智慧交管系统，主要用于城市路口、校园周边、工业园区等交通管理薄弱区域的违规行为检测与辅助执法。

## 核心功能

### 1. 实时目标检测
- 使用 YOLOv8 模型进行实时目标检测
- 支持检测：行人、自行车、汽车、摩托车、公交车、卡车、红绿灯等

### 2. 多目标跟踪
- 使用 DeepSORT 算法进行多目标跟踪
- 支持轨迹预测与速度估计

### 3. 违规行为检测
- **闯红灯检测**：基于红绿灯状态与车辆轨迹分析
- **未戴头盔检测**：行人/非机动车头部检测
- **逆行检测**：基于车辆运动轨迹分析
- **违规停车检测**：基于车辆静止状态与区域分析
- **车辆压线检测**：实时车道线检测与车辆越线判断
- **超速监测**：基于车辆位移计算速度，与限速值比较

### 4. 置信度评估与分级响应
- 综合置信度计算（检测置信度、跟踪稳定性、环境适配度）
- 三级响应机制（低/中/高置信度）
- 高置信度：直接本地处理
- 中置信度：云端二次确权

### 5. TensorRT 模型加速
- 支持 TensorRT 推理加速
- FP16 半精度计算优化
- 可显著提升推理速度

### 6. 豆包大模型云端二次确权
- 接入豆包视觉大模型
- 对中置信度违规进行二次确认
- 支持自然语言交互分析

### 7. 语音播报
- 支持本地语音播报
- DashScope TTS 合成（可选）
- Windows TTS 备用方案

## 安装依赖

```bash
pip install opencv-python numpy ultralytics deep-sort-realtime dashscope requests keyboard
```

## 运行项目

### 方法1：使用启动脚本
```bash
cd e:\output\1
start_zhitong.bat
```

### 方法2：直接运行
```bash
cd e:\output\1
python zhitong\main.py
```

## 控制说明

| 按键 | 功能 |
|------|------|
| SPACE | 本地快速播报检测到的物体 |
| C | 云端图像分析（使用豆包大模型） |
| Q | 退出系统 |

## 配置说明

在 `config.py` 中可以配置：
- 模型路径与类型
- 检测置信度阈值
- 云端 API Key
- 输出路径
- 是否启用 TensorRT 加速

## 技术栈

- **目标检测**：YOLOv8n
- **多目标跟踪**：DeepSORT
- **视觉处理**：OpenCV
- **深度学习框架**：PyTorch
- **云端推理**：DashScope / 豆包大模型
- **语音合成**：DashScope TTS / Windows TTS
- **加速引擎**：TensorRT（可选）
