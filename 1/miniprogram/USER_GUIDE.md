## 1. 注册微信小程序

### 步骤 1：访问微信公众平台
打开浏览器，访问微信公众平台官网：
```
https://mp.weixin.qq.com/
```

### 步骤 2：注册账号
1. 点击右上角「立即注册」
2. 选择「小程序」类型
3. 按提示填写邮箱、密码、验证码
4. 登录邮箱激活账号

### 步骤 3：主体信息登记
1. 选择主体类型（个人/企业/政府/媒体/其他组织）
2. 填写主体信息并上传相关证件
3. 完成微信认证（企业类型需要）

### 步骤 4：小程序信息完善
1. 设置小程序名称
2. 上传小程序头像
3. 填写小程序简介
4. 选择服务类别

## 2. 获取 AppID 和 AppSecret

### 获取 AppID
1. 登录微信公众平台
2. 点击左侧菜单「开发」→「开发设置」
3. 在「开发者 ID」部分可以看到 `AppID (小程序 ID)`
4. 复制保存，后续配置需要

### 获取 AppSecret
1. 在「开发者 ID」部分点击「生成」按钮生成 AppSecret
2. **重要**：AppSecret 只显示一次，请立即复制保存
3. 如果忘记，需要点击「重置」重新生成

### 配置项目
将获取到的 AppID 配置到项目中：
1. 打开 `project.config.json` 文件
2. 修改 `appid` 字段为你的 AppID

## 3. 配置合法域名

### 步骤 1：登录公众平台
1. 登录微信公众平台
2. 点击左侧菜单「开发」→「开发设置」

### 步骤 2：配置服务器域名
在「服务器域名」部分配置以下域名：

| 域名类型 | 域名地址 | 说明 |
|---------|---------|------|
| request 合法域名 | `http://localhost:8001` | 本地开发环境 |
| request 合法域名 | `https://your-api-domain.com` | 生产环境 API |
| socket 合法域名 | `ws://localhost:8001` | 本地 WebSocket |
| socket 合法域名 | `wss://your-api-domain.com` | 生产环境 WebSocket |

### 步骤 3：配置业务域名（可选）
如果需要使用网页授权等功能，需要配置业务域名。

### 注意事项
- 域名必须备案（国内服务器）
- 域名必须支持 HTTPS（生产环境）
- 配置后需要等待 5 分钟生效

## 4. 上传代码到微信开发者工具

### 步骤 1：安装微信开发者工具
下载并安装微信开发者工具：
```
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

### 步骤 2：打开项目
1. 打开微信开发者工具
2. 点击「导入项目」
3. 选择项目目录：`e:\output\1\miniprogram\dist`
4. 填写 AppID（测试可选择「测试号」）
5. 点击「确定」

### 步骤 3：预览和调试
1. 在开发者工具中可以直接预览效果
2. 点击「预览」按钮生成二维码
3. 使用微信扫码在真机上预览

### 步骤 4：上传代码
1. 点击工具栏中的「上传」按钮
2. 填写版本号和项目备注
3. 点击「上传」确认
4. 上传成功后，代码会提交到微信公众平台

## 5. 提交审核与发布

### 步骤 1：登录公众平台
1. 登录微信公众平台
2. 点击左侧菜单「版本管理」

### 步骤 2：提交审核
1. 在「开发版本」中找到刚上传的代码
2. 点击「提交审核」
3. 填写审核信息：
   - 功能页面：选择主要页面
   - 功能描述：简要说明小程序功能
   - 测试账号：如有需要提供测试账号
4. 点击「提交」

### 步骤 3：等待审核
- 审核时间：通常 1-3 个工作日
- 可以在「审核版本」中查看审核进度
- 如果审核不通过，会收到拒绝原因，请根据提示修改

### 步骤 4：发布上线
1. 审核通过后，在「审核版本」中点击「发布」
2. 确认发布，小程序正式上线

## 6. 常见问题

### Q1: 无法获取用户信息？
A: 需要在小程序后台配置「用户信息」权限，并在代码中使用新版授权接口。

### Q2: 请求后端 API 失败？
A: 检查：
1. 服务器域名是否正确配置
2. 域名是否支持 HTTPS（生产环境）
3. API 接口是否正常运行

### Q3: 上传代码时提示包体积过大？
A: 检查：
1. 是否有未使用的资源文件
2. 图片是否压缩优化
3. 是否可以分包加载

### Q4: 真机预览显示空白？
A: 检查：
1. AppID 是否正确
2. 网络是否正常
3. 开发者工具中是否有报错信息

### Q5: 如何修改小程序图标和名称？
A: 在微信公众平台「设置」→「基本设置」中修改。
