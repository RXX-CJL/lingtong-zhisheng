# 智瞳灵声 - 基于视觉识别与云端推理的智慧交管系统

## 项目简介

本项目是一款基于端云协同架构的智慧交管系统，主要用于城市路口、校园周边、工业园区等交通管理薄弱区域的违规检测与辅助执法。

## 核心功能

- **交通目标检测**：基于YOLOv8实时检测车辆、行人等目标
- **多目标跟踪**：使用DeepSORT算法实现目标追踪
- **违规行为识别**：闯红灯、未戴头盔、逆行、违停等检测
- **云端分析**：调用大模型进行模糊样本二次确权
- **语音播报**：实时违规预警播报

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行系统

```bash
cd zhitong
python main.py
```

## 控制说明

| 按键 | 功能 |
|------|------|
| Q | 退出系统 |
| C | 云端图像分析 |
| S | 保存截图 |

## 项目结构

```
zhitong/
├── __init__.py          # 包初始化
├── config.py            # 配置文件
├── video_capture.py     # 视频采集模块
├── detector.py          # YOLO检测模块
├── tracker.py           # DeepSORT跟踪模块
├── violation_detector.py # 违规检测模块
├── speech.py            # 语音播报模块
├── cloud.py             # 云端服务模块
├── logger.py            # 日志记录模块
└── main.py              # 主入口
```

## 配置说明

在 `config.py` 中可配置：
- 模型参数（置信度阈值等）
- 视频参数（分辨率、帧率等）
- 云端服务配置（API Key等）
- 语音播报开关
