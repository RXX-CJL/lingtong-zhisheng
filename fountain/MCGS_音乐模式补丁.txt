' =============================================================
' 音乐模式补丁 (ControlMode = 2)
' 用法：把本段插入 V9.2 脚本合适的位置，共 4 处插入点。
' 原则：ControlMode=0 / 1 的所有判定行一行不动，只在旁边加 =2 的分支。
' =============================================================

' ---------- 插入点 A：在第 2 节「停止态」之前（原第 26 行附近，模式指示灯之后）----------
' 音乐模式指示灯 + 合法值兜底
IF ControlMode < 0 THEN
    ControlMode = 0
ENDIF
IF ControlMode > 2 THEN
    ControlMode = 2
ENDIF
IF ControlMode = 2 AND RunState = 1 AND StopOK = 1 AND EStopOK = 1 THEN
    MusicModeLamp = 1
ELSE
    MusicModeLamp = 0
ENDIF

' ---------- 插入点 B：在第 3 节「运行演出」内，TargetHeight 清零之后、
'                       场景1 的 IF 之前（原第 111 行附近）----------
    ' 音乐模式：M1..M11 由 Python 每 100ms 通过 Modbus 4区[0..10] 写入
    ' 不需要平滑（Python 那边已经做过 attack/release），直接读进来
    IF ControlMode = 2 THEN
        TargetHeight1  = M1
        TargetHeight2  = M2
        TargetHeight3  = M3
        TargetHeight4  = M4
        TargetHeight5  = M5
        TargetHeight6  = M6
        TargetHeight7  = M7
        TargetHeight8  = M8
        TargetHeight9  = M9
        TargetHeight10 = M10
        TargetHeight11 = M11
    ENDIF

' ---------- 插入点 C：第 3 节里三个场景的 IF 全部加上 "ControlMode <> 2 AND"
'   原：IF (ControlMode = 1 AND SceneSelect = 1) OR (ControlMode = 0 AND RunTimer < 250) THEN
'   新：IF ControlMode <> 2 AND ((ControlMode = 1 AND SceneSelect = 1) OR (ControlMode = 0 AND RunTimer < 250)) THEN
'   ——三个场景都要这样包一层，否则音乐模式会跟场景动画打架

' ---------- 插入点 D：RunTimer 递增也要跳过音乐模式 ----------
'   原：IF RunState = 1 THEN
'           RunTimer = RunTimer + 1
'   新：IF RunState = 1 THEN
'           IF ControlMode <> 2 THEN
'               RunTimer = RunTimer + 1
'           ENDIF
'   ——否则 40 秒一轮的计时器会在音乐模式下乱跑，切回连续演出时位置不对

' ---------- 新增变量清单（在 MCGS 实时数据库里建）----------
'   MusicModeLamp  整数    音乐模式指示灯（当开关用，0/1）
'   M1..M11        整数    音乐模式下各喷头目标高度（0..100），绑定 Modbus 4区地址 0..10
'   说明：MCGS Pro 对象类型只有 整数/浮点数/字符串/组对象 四种，
'         没有"数值型""开关型"——那是旧叫法。这里全用整数，
'         因为 Modbus 4区保持寄存器是 16 位整数。

' ---------- Modbus 通道配置 ----------
'   设备0 → 增加设备通道 11 个：
'     通道类型：读写（不是"只读"）
'     数据类型：16位无符号整数
'     起始地址：0，数量：11
'   然后「快速连接变量」绑定到 M1..M11
'   注意：通道名叫"只读10001"不代表不能写——实测写 55 能读回 55

' ---------- 平滑链始终保持不变 ----------
'   TargetHeight1..11 → (原脚本的平滑段) → Height1..11
'   Python 不直接写 Height，只写 TargetHeight 的输入（M1..M11）
'   这样 V9.2 的防屏闪逻辑、灯光映射全部原样生效
