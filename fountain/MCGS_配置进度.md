## GUI 自动化踩到的坑（务必记住）

1. **cua-driver click 必须用 element_token，不能用 element_index**
   （报错：bare element_index is not accepted）
2. **token 来自最新快照**。旧快照的 token 会点空 —— 这是失败 3 次的主因
3. **frame 坐标是物理屏幕绝对坐标**，不是窗口内坐标
   快照尺寸 1568x957 但 frame x 达到 2063，说明跨窗口
4. **MCGS 是 VCL 应用**，background 模式的 Invoke 会被丢弃
   Tab/W 点击要用 delivery_mode:"foreground"
5. **窗口比屏幕宽**：rect (859,77,2779,1248)，屏幕 2560x1600
   → 右边界 2779 > 2560，工作台右侧 Tab 物理上在屏幕外
   → MoveWindow 被拒（error 5 拒绝访问），需先 SW_RESTORE 再试
6. **effect: "unverifiable" 是常态** —— 必须截图验证，不能当成功
