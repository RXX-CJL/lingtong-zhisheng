# 破晓·潮汐 — 音乐智能响应

## 这是什么

用电脑**正在播放的任何声音**（网易云 / QQ音乐 / 浏览器 / 本地播放器 / 游戏）
驱动 11 个喷头的高度。走 Windows WASAPI Loopback，**不是麦克风**——
所以环境噪音不影响，只有真正在放的声音会被识别。

## 怎么用

双击 **`run.bat`** —— 然后放音乐就行。

- `run.bat`        连 MCGS（502 端口），把高度写进去
- `preview.bat`    只看不动，屏幕上显示 11 个喷头实时高度

MCGS 没开也能跑 —— 连不上会自动转成预览模式，不会崩。

## 设计：不是一一对应，是配方混合

原来的做法是「1-6 管低频、7-10 管中频、11 管高潮」——**这是一一对应，效果不好**：
音乐一变只是几个点在跳，看不出整体感。

现在的做法是**每个喷头有自己的配方**（借鉴瑶光的「器官占比」思路）：

```
       低频   中频   高频   鼓点
1      1.00   0.15   0.05   0.85    外圈起点：极重低频
2      0.92   0.22   0.08   0.90
3      0.84   0.30   0.10   0.95
4      0.76   0.38   0.12   1.00    外圈正中：鼓点最重
5      0.68   0.46   0.14   0.95
6      0.60   0.54   0.16   0.90    外圈终点：往中频过渡
7      0.45   0.78   0.18   0.55    内圈起点
8      0.36   0.90   0.20   0.45
9      0.28   1.00   0.22   0.38    内圈正中：中频最重（人声/主旋律）
10     0.20   0.92   0.26   0.32    内圈终点
11     0.55   0.65   0.35   0.70    中心：全频均衡
```

每一列从左到右单调变化 → 形成**连续渐变**，不会出现突变分块。

三层合成：
1. **基底**（35%）所有喷头共享的整体能量 —— 整个水型一起起伏，像呼吸
2. **配方**（65%）每个喷头对低/中/高/鼓点的不同权重 —— 决定性格
3. **偏科**（最多 +0.22）当前哪个频段最强就让它相关喷头更突出 —— 视觉焦点

「偏科」这个说法直接来自瑶光：`reminder.mjs` 里输出
「偏科：最强是「脑」63.2%」——音乐也有偏科的时刻（重低音曲 vs 人声曲），
识别出来让画面跟着聚焦。

## 踩过的坑（都在代码注释里，别再走）

1. **按权重和归一化会把差异除没**
   喷头1（权重和2.05）与喷头4（和2.26）归一化后差 0.008，等于没差。
   → 改成不归一化，按理论最大权重和缩放。

2. **整个 v 除以 recipe_norm 是错的**
   base 和 focus 也一起被除，外围全掉到 10。
   → 只除 recipe 这一项。

3. **「限制同时工作喷头数」用硬裁剪会打成分块**
   外围 6 个争 4 个名额，排名靠后的一起归零，画面上「1/2/3 一组、4/5/6 一组」两截。
   → 删掉这个约束，只保留总高度上限（水泵功率有限，这才是物理真实）。

4. **判断 `h[i] > 1.0` 统计「在工作」是错的口径**
   h 的单位是 0..100，几乎所有喷头都算在工作，这个约束从来没生效过。

5. **量化步长 5.0 太粗**
   把 1-3 分的配方差异直接舍成同一个值。→ 降到 2.0。
   容差也要相应放宽到 step×11（每个喷头各自舍入的累计误差）。

## 已知问题

**MCGS 工程只有 8 个 Modbus 通道，但喷头有 11 个。**
喷头 9/10/11 的高度暂时写不进去。

修法（在 MCGS 里）：设备窗口 → 双击「设备0」→ 增加设备通道到 11 个 → 快速连接变量绑 TargetHeight1~11。

**注意**：通道名叫「只读10001」不代表不能写——实测写寄存器 55 能读回 55。

## 调参

改 `src/mapper.py` 的 `MapperConfig` 和 `RECIPES`：

```python
base_gain:   0.35   # 基底占比（越大整个水型越同步起伏）
recipe_gain: 0.65   # 配方占比（越大各喷头差异越明显）
focus_gain:  0.22   # 偏科加成幅度
total_cap:   560    # 总高度上限（水泵约束）
step:        2.0    # 量化步长
```
